# `analogia/` — `/ground`

**Responsibility under the Northstar** (root `AGENTS.md`). The protocol here keeps a borrowed structure from steering the work unseen. When a framework or an analogy is carried over to a case in play, what the comparison supports is audited claim by claim against evidence the AI can reach; the person's agreement is recorded but does not count as evidence, so the result says what the comparison supports and where that stops.

**Boundary.** `skills/ground/SKILL.md` is the contract for `/ground`; it names any supporting file in its `references/` to read where that file applies. `README.md` and `README_ko.md` explain the protocol to people, and `.claude-plugin/` and `.codex-plugin/` carry what a host needs to list and install it; what the protocol does once invoked is set in the `SKILL.md`.
