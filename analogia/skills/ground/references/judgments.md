# Judgment direction

Direction for judgments the `/ground` contract leaves to the model. Each section is reached from the doc comment of the judgment it names, read at the moment that judgment is made.

## BearsOn

Bearing keeps the check set finite without letting the protocol choose its own exam: a fit claim bears on an intended inference when changing the claim would change that inference's verdict, whether or not the claim is convenient to check.

## checks

The questions an audit raises guide which checks are derived; they add no check that names no current fit claim. An open check state is unmet — the honest default — and is never read as a pass.
