# `merismos/` — `/apportion`

**Responsibility under the Northstar** (root `AGENTS.md`). The protocol here prepares one goal for an autonomous run that no one will be watching turn by turn. The goal is cut into units that each fit one stretch of the run and carry their own way to tell when they are done, with the whole plan shown to the person each turn, so the run has checkable stopping points instead of drifting.

**Boundary.** `skills/apportion/SKILL.md` is the contract for `/apportion`, and the files in its `references/` are parts of that contract it points to where they apply. `README.md` and `README_ko.md` explain the protocol to people, and `.claude-plugin/` and `.codex-plugin/` carry what a host needs to list and install it; what the protocol does once invoked is set in the `SKILL.md`.
