**Verdict: do not merge the files or normative contracts on current evidence; the prior retyping verdict does not formally govern this restatement, but the surviving phase boundary and existing chained entry path still make merger inferior.**

### Reasoning

The old “two non-entailing deficits cannot be one protocol” argument does not disqualify a shared router: this proposal preserves both signatures. Euporia is therefore not the relevant precedent—it has one open `DimensionProjection`/`Coordinate` carrier and one emergent `Axis`, not two live contracts behind a dispatcher (`euporia/skills/elicit/SKILL.md:50-52,70`).

The decisive objection is `topology_free`. It forbids plan requirements from containing `UnitRef`, `Move`, `MoveRegion`, or order-position references, and it is a conjunct of the hard convergence invariant (`merismos/skills/apportion/SKILL.md:120,135-136`). This enforces Merismos’s stated pre-conduct boundary: it apportions and conditions but does not order (`merismos/skills/apportion/SKILL.md:376,569,574`).

**Reasoning:** a simultaneous draft exposing topology while unit conditions remain mutable cannot preserve that boundary structurally. The lexical check can reject explicit topology names; it cannot prevent conditions from being implicitly shaped around visible topology.

A merged surface could preserve it structurally only through a phase-indexed information barrier:

1. `Apportioning`: topology state is unavailable; units and conditions converge and are frozen.
2. `Conducting`: only then instantiate topology, consuming the frozen plan opaquely and placing—never re-deriving—its conditions.

That second behavior is already `/conduct`’s contract (`hyphegesis/skills/conduct/SKILL.md:128-140,477`). Its cost is decisive: the surface is one, but the procedure remains two, with two successive draft/gate regions and no simultaneous draft. Epistemically it is indistinguishable from the existing composition; only command spelling or display continuity differs.

The tree already supports that composition without another user invocation: a user-declared `/apportion → /conduct` chain relays across the seam (`merismos/skills/apportion/SKILL.md:588`), while `/conduct` binds a live plan directly or dereferences its navigation block (`hyphegesis/skills/conduct/SKILL.md:156-170`). If a host fails to realize that automatic transition, that is routing/platform behavior, not evidence for co-locating normative contracts; platform realization is distinguished from the `SKILL.md` contract, and execution channels lie beyond the epistemic layer (`AGENTS.md:22,39-42`).

### What would change it

1. **Structural preservation:** Yes, progressive disclosure can preserve `topology_free`, but only by withholding topology until the apportioned plan has passed `hard_invariants_hold` and been frozen. That produces one surface but still two procedures. It differs from today’s declared chain only as user-interface realization—one command or persistent document—not as an epistemic morphism.

2. **Better third option:** combine (a) and (b): make only `/apportion` Phase 1 draft-first, then use the already-declared chain. Phase 1 currently packs and settles one anchor at a time (`merismos/skills/apportion/SKILL.md:172-182`); `/conduct` already presents the whole topology before opening contested slots (`hyphegesis/skills/conduct/SKILL.md:403-409`). This captures the unit-recognition reduction while preserving the structural boundary and canonical pointer seam. If one command token remains desirable, place an alias/router above the two contracts rather than putting both normative contracts in one file.

3. **Empirical threshold:** `j` alone does not decide merger because the third option captures its benefit. The unmeasured deciding quantity is the net friction difference between:

   - draft-first `/apportion` plus declared chaining, and
   - a staged merged surface.

   Measure per historical or pilot run: units `u`, contested/reopened units `j`, opened topology slots `k`, extra seam turns, context-restatement turns, and user corrections. Raw session sources are identified for Codex and Claude (`anamnesis/skills/recollect/references/codex.md:18`, `anamnesis/skills/recollect/references/claude.md:11`); the repository already specifies slash-command and correction extraction (`epistemic-cooperative/agents/session-analyzer.md:67-71,136-153`). A stable reduction beyond the chained alternative—without topology contamination or increased single-mode burden—would change the verdict.
