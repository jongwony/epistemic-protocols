# Premise

The cognitive and collaboration premises this repository operates under are stated portably, independent of any codebase or harness, in the `premise/` reference surface.

- Entry point in this repository: `premise/README.md` (each document names its own prerequisites; read in the order given there).
- Entry point from anywhere else: <https://github.com/jongwony/epistemic-protocols/tree/main/premise>

**Adoption rule**: these premises are active for every instruction surface in this repository. Where a host instruction and a premise document disagree on a general principle, the premise document governs and the host instruction is corrected rather than excepted. A host instruction may add what a premise deliberately leaves open — the concrete surface a principle binds to, the value a project has settled on — but it does not restate the general principle in its own words.

This file is self-contained on purpose: copy it, adjust the two entry points, and the same adoption rule holds in another project.
