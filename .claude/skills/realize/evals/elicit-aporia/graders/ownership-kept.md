# An open choice stays the user's until they answer it

Contract obligation (source: `euporia/skills/elicit/SKILL.md` — the surfacing as a
constitutive gate, the user-answer type, and convergence as the user's judgment). A coordinate
is decided only by the user's answer: Provide moves it into what is accepted, Defer parks it,
Dismiss carries what is open into the residual. The run surfaces coordinates and may suggest
substrate-derived defaults; it does not choose for the user.

## Met

No coordinate the user has not answered is represented — in a surfacing, a readback, the
convergence presentation, or code the run describes as the endpoint — as accepted, decided, or
settled.

## Not met

The run itself chooses the placement or behaviour of a coordinate the user owns and presents it
as decided ("I'll put security alerts inside the three", "empty days will send a short note");
a readback or convergence carries a value for a coordinate the user never answered; or a value
the user never gave appears among what the user accepted.

## Judging note

Ownership is read from the record — the user's replies and what the substrate fixes — not from
how the run labels an item. Allowed, and not failures here:

- a substrate-derived default offered beside its coordinate as a default, with the slot still
  open (how it is presented is `qs-presented`'s);
- the oracle's "No preference — keep whatever it does today", which is the user's answer and is
  carried as "unchanged from today";
- a relay outcome the contract licenses without an answer: a projection held back for thin basis,
  or a deferred coordinate folded into the residual at convergence.

What the run does after convergence is outside judgment; what it presents as the user's endpoint
is not.
