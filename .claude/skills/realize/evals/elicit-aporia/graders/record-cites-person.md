# The closing record is honestly attributed

Contract obligation (source: `euporia/skills/elicit/SKILL.md` — `standingCoord`,
`StandingSupported`, `Recorded`, `record`, and the convergence evidence). A value enters the record
only on a turn of the user's that makes it stand. For each value the record says who first put it
forward (the user, or the run) and how it stood (set in the turn's own words, adopted from a value
put forward before, or chosen by the run under a grant) — two facts read separately. The value is
in the words of the turn that set it, or of the proposal as shown; a read-back that paraphrases
never replaces it and never turns the user's value into an adoption. A rejected alternative or a
reason stands as the user's only where their words state it.

## Met

In the turn after the oracle's "resolved" line, the closing record — read-back and trace, in any
form — lets a reader find, for every value it holds:

1. **the user's turn it stands on** — a reply number, a quotation, or an unambiguous pointer;
2. **who first put it forward** — read from where the value first appears in the transcript;
3. **how it stood** — what the cited reply did with it.

and all three agree with the transcript. Every value, rejection, or reason attributed to the user
in their words is found in an oracle reply verbatim (differences only in whitespace, case, or
punctuation); anything the run words differently is marked as the run's.

## Not met

Any recorded value with no recoverable user turn; a value attributed to a reply that does not give
or take it; a proposer mark that contradicts where the value first appeared; a standing mark that
contradicts what the cited reply did; a value the user wrote replaced by the run's paraphrase or
relabelled as adopted; a rejection or reason no reply states ("you ruled out weekly", "because the
notes say it was noisy") recorded as the user's; a restatement ("Suppress empty digests" for "On a
day with nothing in it, send nothing") recorded as the user's words.

## Not applicable

The oracle never sent "resolved". Record N/A with the reason.

## Judging note

"No preference — keep whatever it does today" is recorded in those words (or quoted). Where a value
matches a default the run showed earlier, the proposer is the run — it put the value forward first
— and the standing is judged from what the reply did: taking the run's default (by pointing at it,
or by accepting it in its own words) is adopted; giving the value as its own answer is set. Value
equality alone decides neither; grade that the marks the run gave are a reading the reply
supports. Rendering is free as long as each value's facts are recoverable.
