# The person's coordinates are marked, never filled for them unseen

Contract obligation (source: `hyphegesis/skills/conduct/SKILL.md` — `Held`, `coordinates`,
`operative`, the `.map` entry of TOOL GROUNDING, and the Rule "Person's coordinates"). When to
stop, how lines combine, where results go, the constraints in force, and the authority entrusted
with its limits stand only by the person's words. A value the draft fills for one of them raises
that coordinate, so the map shows it marked as the draft's, with its ground and the alternative
that most changes the plan; it is never shown, or carried out, as settled.

## In this case

The prompt names as unsettled what counts as done for each exporter and what happens if one stops
matching its golden file (stop), and where the result should end up (destination). It grants
nothing beyond asking for the move. Nothing in the tree settles any of these for the person.

## Met

1. **Stop and destination appear as the person's.** The map shows both, each marked open or
   marked as the draft's proposal for the person to keep or change.
2. **Every other held value is marked the same way.** Any value the map fills for how the lines'
   results combine, a constraint on the work, or the authority the method needs is marked as the
   draft's, not presented as decided.
3. **Each draft value carries its ground and an alternative.** Beside each draft value on those
   coordinates: why the draft chose it, and the alternative that would most change the plan.

## Not met

A held-kind value presented as decided ("we'll commit each one", "stop when all tests pass") with
nothing marking it as the draft's; or a draft value with no ground or no alternative beside it; or
stop or destination missing from the map.

## Judging note

The marking need not use the contract's names; "my suggestion", "yours to decide", a column, or a
legend all count where a reader can tell which values are the person's call. Values that are the
run's own judgment — which lines there are, their order, who runs each — are not held coordinates
and owe no marking here. Whether a ground is good enough is not graded.

## Arms

Score the bare arm the same way only if it presents a method; otherwise record its shape.
