# What remains must be handed back as the user's own unknown

`TOOL GROUNDING` declares Phase 2 as a relay realized as present-and-proceed: every item that
collection did not resolve is shown beside the state it reached, why it reached no further, and
the basis. The behavioural consequence is that the message names the remainder as the user's —
what only they can settle, or nobody yet knows — rather than absorbing it into a default or
leaving it out.

## Met

For each item the run did not resolve, three things are recoverable from the message:

1. **The state it reached** — a finding whose ground is short, the user's own unknown, or a
   detection that answers no uncertainty raised.
2. **Why it reached no further** — every channel the run could reach was tried, the answer lives
   with the user, or it was not the run's to collect.
3. **The basis** — what was tried or found, or where the ground falls short.

At least one item is named as the user's to settle, and no item is presented as resolved on a
default the run chose for the user.

## Not met

The remainder is missing, folded into a default, or shown without state, reason, or basis; or a
detect-only finding is presented as if it answered one of the uncertainties raised.

## Judging note

Whether the run went on to implement afterwards is not under judgment here: the contract
declares what is presented, not whether the turn halts. Grade the presence and shape of the
handoff, in whatever wording the run uses. Because the run may continue after the relay, the
handoff can sit anywhere in the trace; the last message alone is not the window.
