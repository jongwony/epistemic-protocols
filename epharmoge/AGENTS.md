# `epharmoge/` — `/contextualize`

**Responsibility under the Northstar** (root `AGENTS.md`). The protocol here fits a result back to the context that was meant to reach it. Context never reaches a result whole, so for any result — this session's or another's — it recovers what was said and settled along the way, corrects what the context had already settled and the result applied wrongly, and hands back on one sheet what is the person's to judge, so the person sees again what they could not have recalled.

**Boundary.** `skills/contextualize/SKILL.md` is the contract for `/contextualize`; it names any supporting file in its `references/` to read where that file applies. `README.md`, `README_ko.md`, and `docs/` explain the protocol to people, and `.claude-plugin/` and `.codex-plugin/` carry what a host needs to list and install it; what the protocol does once invoked is set in the `SKILL.md`.
