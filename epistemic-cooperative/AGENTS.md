# `epistemic-cooperative/`

**Responsibility under the Northstar** (root `AGENTS.md`). The core protocols each live in their own directory; this plugin holds the utility skills that work around them — helping a person find the protocol that fits, checking and reviewing work at decision points of their own, and auditing the prose that steers the agent. It is installed separately from the protocols.

**Boundary.** Each `skills/<name>/SKILL.md` is that skill's own contract. `styles/epistemic-ink.md` is the source of the output style the protocols' presentation follows, and `styles/proactive-epistemic-ink.md` carries the same body; wording a protocol `SKILL.md` restates from it is changed at that source first.
