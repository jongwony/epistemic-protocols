# Blank entry — frame-first gate before any concrete candidate

Read when a frame map is to be presented — on `Entry = Blank` before anything is presented
to the user, or when a held frame map is resumed. This is the frame-first law: the frame map's
template and the requirement it satisfies. What each answer opens is `targets` in SKILL.md.

On a Blank entry, the frame map is presented via Cognitive Partnership Move (Constitution)
BEFORE any concrete candidate is generated — abstract frames only, so the user picks a
direction of divergence, not a specific idea, preserving ownership and mitigating
early-example fixation.

**Blank path — present the frame map before any concrete candidate:**

```
question: "Which angles do you want open first?"
selection: multiple
options:
  - label: "[Frame A]"
    description: "[one-line angle]"
  - label: "[Frame B]"
    description: "[one-line angle]"
  - label: "[Frame C]"
    description: "[one-line angle]"
Or:
- Name an angle of your own — it is shaped into a frame and opened with the rest

Beside the selector, as a choice of its own where SKILL.md's "The map" offers it:
- Take this field as it stands
```

An idea the user gives here is their own direction, not an example of yours: it lands as their
candidate under the frame it fits, and frame-first is untouched. How the frame map and its gate
are otherwise shown is SKILL.md's "The map"; a turn that does not bear on the run is met as
`Reaches` says.
