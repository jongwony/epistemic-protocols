# Seeded entry — expand-first, no gate

Read when `Entry = Seeded(seeds)` — before the first pass runs. This is the expand-first
law: why no gate precedes generation.

**Seeded path — no gate.** Frames derived from the seeds go straight to a first pass
(expand-first): the user already committed concrete material, so the early-example
fixation risk the frame map exists to avoid does not apply the same way here.

How many derived frames the first pass opens is your judgment. Every frame left closed shows
on the map as unexplored; what a later continue opens is `targets` in SKILL.md. How the seeds enter the map, with their origins, is `candidates` in SKILL.md.
