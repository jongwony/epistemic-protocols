# Seeded entry — expand-first, no gate

Read when `Entry = Seeded(seeds)` — before Phase 2 runs its first generation pass. This is
the expand-first law: why no gate precedes generation, and how the original seeds enter
the round.

**Seeded path — no gate.** Frames derived from the seeds proceed straight to Phase 2
(expand-first): the user already committed concrete material, so the early-example
fixation risk the Blank-path gate exists to avoid does not apply the same way here.

On the very first pass of a Seeded entry, the original seeds are promoted to candidates
under the frame each lands in — each keeping the origin its seed carried (utterance
fragments `origin=User`) — alongside whatever the frames generate as `origin=AI`; every
later pass tags its output `origin=AI`.
