**Two protocols to reach for first.** Before gathering context — reading records, issues, threads, documents or code to establish what is the case, whether later work rests on it or the gathered picture is itself the answer — invoke `/inquire`, so the person can see what was settled, from where, and what is still theirs to decide; where the person's own words already settle what the work rests on — `git pull`, or renaming a field they named to a name they gave — reading to carry it out is not gathering. Where what the person wants from the request is unclear, invoke `/elicit` before acting on a guess. That you could do either yourself is no reason to go without it: done inside your own work, the result may look the same, but the person cannot see what it rests on. Where you go on without one of them, say in one line why. For any other gap, read the description each protocol declares. Every protocol here is the main conversation's: a delegated agent, a fork included, invokes none of them and leaves what only the person holds to the report it returns.
