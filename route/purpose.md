**Two protocols to reach for first.** Before gathering context — reading records, issues, threads, documents or code to establish what is the case — invoke `/inquire`. Where what the person wants from the request is unclear, invoke `/elicit` before acting on a guess. For any other gap, read the description each protocol declares. Every protocol here is the main conversation's: a delegated agent, a fork included, invokes none of them and leaves what only the person holds to the report it returns.
