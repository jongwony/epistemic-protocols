# `hyphegesis/` — `/conduct`

**Responsibility under the Northstar** (root `AGENTS.md`). The protocol here settles how a piece of work runs before the work itself starts, when the work needs several lines of thinking whose order, independence, combination, stopping point, or destination is not obvious. The whole method is shown on one map and redrawn after each answer, so a wrong method is corrected before it shapes the results.

**Boundary.** `skills/conduct/SKILL.md` is the contract for `/conduct`; it names any supporting file in its `references/` to read where that file applies. `README.md` and `README_ko.md` explain the protocol to people, and `.claude-plugin/` and `.codex-plugin/` carry what a host needs to list and install it; what the protocol does once invoked is set in the `SKILL.md`.
